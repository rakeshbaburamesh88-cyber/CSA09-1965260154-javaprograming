# Java Assignment 3 – Exception Handling & Multithreading

Requires JDK 11+ (tested with Java 21). Run each program from inside its folder.

| Folder | Compile | Run |
|---|---|---|
| Q1 | `javac ATM.java` | `java ATM` |
| Q2 | `javac StorageDemo.java` | `java StorageDemo` |
| Q3 | `javac SalesReport.java` | `java SalesReport` (needs `sales.txt`, included) |
| Q4 | `javac *.java` | `java ThreadDemo` / `java ExecutorDemo` |
| Q5 | `javac SeatBooking.java` | `java SeatBooking` |
| Q6 | `javac *.java` | `java TokenCounter` / `java QueueDemo` |
| Q7 | `javac ResultProcessor.java` | `java ResultProcessor` (sample `student1/2/4.txt` included; `student3.txt` is intentionally missing to show a failure) |

In VS Code (with the "Extension Pack for Java"), open a file and click **Run** above `main`.
