Java Assignment 1 - Campus Smart-Parking System
Open this folder in VS Code (File > Open Folder). Each TaskNN folder is independent
(class names such as Vehicle repeat across tasks), so run one task at a time:

  cd TaskNN
  javac *.java
  java <MainClassName>

Task 02 asks for input (vehicle number, then minutes, e.g. 90).
Task 10 uses a package:  cd Task10 ; javac parking/EncapsulationDemo.java ; java parking.EncapsulationDemo
