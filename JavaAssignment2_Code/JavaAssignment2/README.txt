Java Assignment 2 (CO2) - Strings and Collections
Open this folder in VS Code (File > Open Folder). Each TaskNN folder is independent,
so run one task at a time:

  cd TaskNN
  javac *.java
  java <MainClassName>

Main classes: Task01 TicketBuilder, Task02 PlaylistDemo, Task03 StudentDemo,
Task04 PharmacyInventory, Task05 LeaderboardDemo, Task06 Triage, Task07 PlaylistRedesign.
